# The sampled instruments (decisions D96 to D100): family | instrument | style | sustains | source | options
#
# One line per style. An instrument is the lines that share its name; its number is the order in
# which it first appears and its styles are numbered in order, both saved in patches: never
# reorder or remove lines, add new instruments at the end.
#
# "sustains" says whether a held note should go on for as long as the key is down (yes: the
# library builder gives every sample a loop) or ring out as recorded (no).
# "source" is the folder under audition/libraries the style is built from. Both libraries are CC0.
# "options" are for the library builder alone (tools/audition/build_library.py explains them).
# The builder takes each recording's note, keys, velocities, level and tuning from the mapping
# files the recordings' author publishes; the options say which mapping file, where the
# author's mapping is set aside, and how the tuning is measured where the author gives none.
# The plugin reads the first four columns.
